Distributed rate limiter demo

Two gateway instances share one Redis limit. These keys are public demo credentials for the mock upstreams on this host.

  • Acme key: gwk_acmedemo_portfolio_public_demo_key
  • Globex key: gwk_globexdemo_portfolio_public_demo_key
curl -i "$ORIGIN/api/orders" -H "X-API-Key: gwk_acmedemo_portfolio_public_demo_key"

Repeat that request. After the token bucket is empty the gateway returns 429. /api/search uses a sliding window, and /api/flaky trips the circuit breaker.
